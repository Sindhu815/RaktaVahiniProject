# Rakta Vahini 🩸

Rakta Vahini is an Android-based Blood Donation Management Application developed to help connect blood donors, receivers, and hospitals during emergency situations. The application provides a fast and efficient way to search for blood donors based on blood group and availability, helping reduce delays in critical medical emergencies.

---

# 📌 Project Objective

The main objective of Rakta Vahini is to create a digital platform that simplifies blood donor management and emergency blood requests. Traditional methods of finding donors through calls or social media are time-consuming and unreliable during emergencies. This application aims to provide a centralized and user-friendly solution for quick communication and donor access.

# 🧩 Architecture Used

The project follows the **MVVM (Model View ViewModel)** architecture pattern for better code organization, maintainability, and scalability.

---

# 📱 Application Modules

## Donor Registration Module
Allows users to register as blood donors with their personal details and blood group information.

## Blood Search Module
Helps users search donors based on required blood groups.

## Emergency Request Module
Allows quick blood requests during emergencies.

## Communication Module
Provides direct communication using WhatsApp integration.
